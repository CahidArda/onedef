## A full app: Misrava

[Misrava](https://github.com/CahidArda/misrava) teaches French songs line by line. It's built
on onedef end to end:

- **The contract:** songs and concepts as collections, the lesson pipeline as actions.
- **One UI:** the website, and the same screens rendered inside Claude as an MCP App.
- **Auth:** every page and endpoint behind Clerk; MCP clients sign in with OAuth (CIMD).
- **A process:** the connected agent can write a lesson itself, part by part, with
  `songs_translate_start` / `_next`. The website's button runs the same process with
  OpenAI.
