---
title: Packages
description: What each package does, and when you need it.
---

Install only what you use. Everything depends on `onedef` except `@onedef/mcp-elicitation-workflow`,
which stands on its own.

| package | what | you need it for |
| --- | --- | --- |
| `onedef` | the contract, `implement`, `createClient`, the `local()` and `http()` transports, errors | always; see [the typed client](/docs/clients) |
| `@onedef/orpc` | `toNextHandlers`, `toFetchHandler`, `generateOpenApi`; `/client` → `rpc()` | [REST, RPC and OpenAPI](/docs/serve/rest), and the `rpc()` transport |
| `@onedef/mcp` | `createMcpHandler`, `serveMcpStdio`, `protectedResourceMetadata`; `/app` → `mcpApp()`, `launch()` | an [MCP server](/docs/serve/mcp), and the `mcpApp()` transport for [one UI](/docs/clients/one-ui) |
| `@onedef/next` | `withOnedef`; `/server` → `serveMcpApp()`; `/mcp-app` → `defineMcpApp()` | the [MCP App](/docs/clients/one-ui), built by Next.js |
| `@onedef/cli` | `runCli` with `login` / `logout` / `whoami`, `toSkillMarkdown` | a [CLI](/docs/clients/cli) |
| `@onedef/query` | `createQueryUtils` | [TanStack Query](/docs/clients/tanstack-query) |
| `@onedef/store` | `implementStore`, `memoryStore`; `/fs` → `fsStore`; `/redis` → `redisStore` | [persistence written for you](/docs/guides/storage) |
| `@onedef/process` | `runsIn`, `memoryRunStore` | [processes](/docs/guides/processes) |
| `@onedef/docs` | `writeMintlifySite` | a generated [API docs](/docs/serve/api-docs) site |
| `@onedef/mcp-elicitation-workflow` | `createWorkflow`, `workflowRuns`, run stores; `/mcp` → `registerWorkflowTool`; `/redis` → `redisRunStore` | [MCP tools that ask and continue](/docs/mcp-elicitation-workflow), with or without onedef |

**Schemas** are any [Standard Schema](https://standardschema.dev) validator with JSON Schema
support: zod 4.2 or later, valibot or arktype. Nothing to register.

**Runtimes:** the server pieces are plain fetch handlers, so they run on Node, Bun, Deno and
Cloudflare Workers. `@onedef/next` needs Next.js 16.
